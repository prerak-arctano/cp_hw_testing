# cp_hw_testing
Hardware Testing Ver_1 for testing all the hardwares

Hardware Testing of the new CP_Testing (Testing all peripherals) which includes:
(1) Power of LORA module.
(2) Power of 4G_LTE module.
(3) Flash IC using SPI (Write and Read the content).
(4) RTC (Timing update) (0x51)
(5) I2C Scanner
